# ai-engineering-journey
Personal Fresh Water Aquarium Monitoring System - a full-stack data pipeline that ingests weekly water chemistry readings and feeding logs, stores them in SQLite, and predicts next week's nitrate levels using ML. Built to explore end-to-end data engineering: SQL schema design, Pandas analysis, time-series forecasting, and systematic logging.
